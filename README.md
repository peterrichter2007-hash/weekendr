# Maison Voyage — Cheap, Beautiful Weekends in Europe

A premium Apple-style AI travel platform that finds the cheapest beautiful weekend trips in Europe. Built as a single-page app with a tiny Express proxy for the AI calls.

> **Live data**: Skyscanner / Booking.com / GetYourGuide (deep-link search URLs), Open-Meteo (weather), Wikipedia REST API (city + landmark imagery). AI city pages generated by Claude via your own API key (stored only in your browser).

---

## Quick start

```bash
git clone https://github.com/peterrichter2007-hash/weekendr.git
cd weekendr
npm install
npm start
```

Then open <http://localhost:3000/>.

├── vercel.json         # Vercel deploy config

### Why everything in one file
The frontend is a single, self-contained HTML file. It's deliberate: drag it into any browser, drop it into any AI for analysis, host it anywhere. No build step. The CSS is in one `<style>` block, the JS in one `<script>` block, each split into clearly-labelled sections.

### How the file is organised inside

**CSS sections** (in order):
- Design system tokens (`:root`)
- Reset + typography
- Nav + hero + manifesto
- Editorial grid + rails
- Concierge (AI form, slider, autocomplete)
- Map (Leaflet integration + sidebar)
- City detail (hero, deals, hotels, activities, restaurants, weather, guides)
- Story reader
- Modal / loading / results
- Glass utilities (`.glass-card`, `.has-placeholder`, image fade)
- Section frosted veils (Vision-Pro layered look)
- Responsive

**JS sections**:
- `DATA` — collections, smart destinations, city coords, autocomplete cities
- `IMAGE SYSTEM` — Wikipedia REST API fetcher + typographic placeholders
- `WEATHER` — Open-Meteo fetcher
- `PARTNER LINKS` — Skyscanner / Booking / GetYourGuide URL builders
- `AVAILABILITY` — deterministic heuristic (no random)
- `MAP` — Leaflet init, tile toggle, markers, sidebar
- `CONCIERGE` — form, slider, autocomplete, AI generation
- `RAILS` — collection rendering
- `CITY DETAIL` — open/close, hotels, activities, restaurants, guides
- `RESULTS` — AI results drawer
- `STORIES` — editorial reading content + reader modal
- `MOTION` — smooth scroll, parallax, magnetic, ambient orbs

## Configuration

The Anthropic API key is **never stored on the server or in the repo**. The user pastes it once in the browser modal and it's saved to `localStorage` under `mv_api_key`. The proxy in `server.js` only forwards the key from the request body to Anthropic.

You don't need a `.env` file for local development.

## Working with multiple AIs

This project is set up so any AI assistant (Claude, Cursor, Copilot, GPT) can pick it up cold:

1. **Open `public/index.html`** in your editor — the entire frontend is there
2. The sections are labelled with `/* SECTION NAME */` headers, so you can quickly point an AI at the bit you want to change
3. **Don't ask AIs to refactor it into modules** unless you're prepared to set up Vite / a build tool — the single-file layout is the design choice

### Common asks that work well

- "In `public/index.html`, find the `STORIES` section in `<script>` and add a new story for X"
- "Strengthen the glass effect on `.glass-card` — increase the blur and add a stronger top highlight"
- "Add a new city to `smartDestinations` with realistic Skyscanner prices from Berlin / Munich / Zurich"
- "Open the `CITY DETAIL` JS section and add a new section between activities and restaurants"

## Things that are intentional, not bugs

- **Hotel cards show typographic placeholders, not photos.** We don't have a Booking partner API, and showing a generic stock photo would imply it's the actual hotel. Hopper and Hotels.com do exactly the same during loading.
- **All images come from Wikipedia.** If Wikipedia doesn't have an article (e.g. invented hotel name "Casa Sole"), the typographic placeholder kicks in. No random Unsplash fallbacks.
- **Smooth-scroll wheel inertia is enabled.** If you want native scroll behaviour for testing, scroll with the trackpad (it's only the wheel that's intercepted).
- **The map only wheel-zooms once you've clicked into it.** This stops the map hijacking the page scroll.

## Roadmap candidates

If you want to extend the platform, the obvious next steps:

- **Real hotel images**: requires Booking.com affiliate program. Swap `renderHotels` to fetch from the partner API.
- **Real flight prices**: same — Skyscanner Travelapi partner access.
- **Authentication + saved trips**: needs a backend. The current Express proxy is just a stateless forwarder.
- **Multilingual**: add a `lang` toggle, wrap all UI strings in `t('key')`, swap the AI prompt voice.
- **ES Modules + Vite**: split the single file into modules. Real engineering investment.
